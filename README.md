# vibe-coding

个人 vibe coding 规范库。**所有新项目从这里起步：复制 `AGENTS.md` → 填占位符 → 开工。**

## 文件

| 文件 | 用途 |
|---|---|
| `AGENTS.md` | 公共 AGENTS 母版：【】占位符区（概览/目录/命令/约定，每个项目自己填）+ 公共规范区（文档与计划 / 更新日志 / Tag / 行为准则，勿改） |

## 用法

1. 复制本仓库 `AGENTS.md` 为新项目根目录的 `AGENTS.md`。
2. 填充全部【】占位符（占位符填完后删除【】括号）。
3. 多模块仓库：各模块目录可另放模块级 AGENTS，只写"换个模块就会变"的内容，公共规范链接回根文件。

## 原则
