# vibe-coding

个人 vibe coding 规范库：AI 协作开发的公共模板、规范与好用的技能合集。
**所有新项目从这里起步**：复制模板 → 填占位符 → 开工。

## 目录

| 文件 | 用途 |
|---|---|
| `AGENTS.template.md` | 项目根 AGENTS.md 母版：项目概览/目录/命令/约定（填空）+ 公共规范（文档与计划、更新日志、Tag、行为准则，勿改） |
| `AGENTS.module.template.md` | 多模块仓库的模块级 AGENTS 模板：只写"换个模块就会变"的内容 |
| `skills/` | 好用的技能、提示词、工作流收藏 |

## 用法

1. 新项目：复制 `AGENTS.template.md` 为项目根 `AGENTS.md`，填充全部【】占位符。
2. 文件头注释保留，并注明所用模板版本——公共规范升级时按版本对比跟进。
3. 多模块仓库：各模块目录另放一份 `AGENTS.module.template.md` 实例。

## 原则

- 公共规范（文档与计划 / 更新日志 / Tag / 行为准则）只有一份源头，就在本仓库模板里；项目内是实例。
- 模板内容经过实际项目检验才升级（当前检验场：pan-go 四网盘 SDK 统一仓库）。
